# v0.1.6 — 托盘弹出面板（取代详情窗口）+ 局域网 IP 修正 + 应用图标

**日期**：2026-10-07
**Release**：https://github.com/yosh3289/speedforce/releases/tag/v0.1.6

## 一句话概括

按用户请求，参考 win-codexbar 做了**左键托盘图标弹出的深色面板**：贴着任务栏弹出，点别处 / 按 Esc / 再点图标即收起，**完全取代**原来的详情窗口。用户试用中报告的三个问题一并修掉：局域网 IP 显示成无线网卡的 169.254 地址、展开“网络详情”会挪动面板、设置窗口没有闪电图标。

## 新功能：托盘弹出面板

**交互**
- 左键托盘图标：开 / 关面板。防抖 300ms：面板开着时点图标，鼠标按下先让面板失焦收起，抬起时的 tap 不能又把它打开。
- 位置：取点击时光标所在显示器，按“显示器区域 vs 工作区”判断任务栏在哪条边（四个方向都支持，自动隐藏的任务栏按底部处理），贴边并沿任务栏以光标为中心、夹在工作区内。多显示器下验证过（用户的第二块屏）。
- 收起：应用失去前台（fyne `Lifecycle.SetOnExitedForeground`）或 Esc。面板只隐藏不销毁（避开 v0.1.5 那类“关闭后打不开”和 GL 资源反复创建）。
- 置顶、无任务栏按钮 / Alt-Tab 项（`WS_EX_TOOLWINDOW`）、Windows 11 圆角（DWM，尽力而为）。
- 右键菜单不变，“显示详情”也打开面板。

**内容**（深色主题只套在面板上，`container.NewThemeOverride`，设置窗口不变）
- 头部：`SpeedForce  5/6 在线` + 检测模式；公网 IP · 国家。
- 6 路连接：名称 + 延迟条（0–3000ms；正常蓝 / >3s 黄 / 失败红并显示“失败”）+ 毫秒数。
- 官方状态（圆点颜色沿用原规则）。
- `▸ 网络详情`（可展开）：局域网 IP、城市 / ISP、各路 HTTP 状态码。
- 底部：Claude / OpenAI / Gemini 状态页按钮 + 设置齿轮。

**结构**：`internal/ui/panel`（`panel.go` 生命周期与开关、`view.go` 由 `core.State` 构建界面、`theme.go` 深色主题）；`internal/platform/flyout*.go`（纯函数 `PlaceFlyout` + Windows 的 `PositionFlyout` / `RedockFlyout` / `StyleFlyout`，HWND 经 fyne `driver.NativeWindow.RunNative` 获取）；托盘 `Callbacks` 新增 `OnTap`；删除 `internal/ui/detail`。设计文档：`docs/superpowers/specs/2026-10-07-tray-flyout-panel-design.md`。

## 试用中发现并修掉的问题

1. **第二次左键开关反了**：首次打开时为去掉任务栏按钮要原生地隐藏再显示窗口，隐藏瞬间同步触发“失焦”把面板收起（程序以为关了，屏幕上却开着）。修复：样式处理期间忽略它自己引起的失焦。
2. **面板被其他窗口挡住**：未被激活时不在最上层。修复：`HWND_TOPMOST`。
3. **次要文字太暗、⚡ 不显示、长 ISP 撑宽面板、行距过大**：用 fyne 测试渲染器离屏画出面板逐项调整（次要文字颜色、去掉字体里没有的 ⚡、自动换行、收紧内边距）。
4. **局域网 IP 不对（用户发现）**：显示的 `169.254.123.95` 是**未连接的无线网卡**的链路本地地址；实际在用的是有线网卡的 `192.168.147.168`。原实现取 `net.InterfaceAddrs` 的第一个非回环 IPv4，顺序不确定（该机有 8 块网卡）。修复：取系统出站路由所用的本机地址（UDP connect，不发包），退回时优先私网地址，永不选回环 / 169.254 / 非 IPv4。
5. **展开“网络详情”会挪动面板（用户发现，修了两轮）**：
   - 第一轮：面板贴着任务栏，变高只能往上长，顶部跳动 → 改为**固定高度**（按收起状态）+ 内容区滚动 + 底部按钮固定，展开时自动滚到详情处，状态刷新保留滚动位置。
   - 第二轮（用户反馈仍会**往左挪**）：每次重新渲染后的“重新贴靠”用的是**当前光标位置**作为横向中心，而光标正停在面板左侧的“网络详情”按钮上。修复：只有打开时按光标定位；重新贴靠一律以面板自身中心为锚（`RedockFlyout`），横向不动。
6. **设置窗口没有闪电图标（用户发现）**：程序从未设置应用图标，带标题栏的窗口显示工具包默认图标。修复：把闪电 SVG 设为应用图标（fyne 自动栅格化）。
