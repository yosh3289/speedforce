# v0.1.7 — 网络详情里的 HTTP 状态码加上简短说明

**日期**：2026-10-07
**Release**：https://github.com/yosh3289/speedforce/releases/tag/v0.1.7

## 一句话概括

用户问：网络详情里各服务商后面的 “HTTP 404 / 403 / 421” 代表什么、有没有实用意义。答案是：探测是对各服务**根地址**发的**匿名 HEAD 请求**（UA `SpeedForce/1.0 (+probe)`，不带登录），所以 404、403、421 等多数 4xx 只说明“请求已经到达服务商的服务器”，属正常；真正有用的是它**变了**的时候。本版在每个状态码后面加一句简短说明，并在列表上方加一行提示。

## 说明规则（`statusCodeNote`）

| 结果 | 说明（中 / 英） | 含义 |
|---|---|---|
| 2xx / 3xx | 正常 / OK | |
| 其他 4xx（404、403、421…） | 可达 / reachable | 匿名探测被拒或路径不存在，但服务器已应答 |
| 407 | 代理需要认证 / proxy needs auth | 自己的代理配置问题 |
| 429 | 被限流 / rate limited | |
| 5xx | 服务器出错 / server error | 服务商服务端问题（程序也判为不在线） |
| 无响应 | 未到达服务器 / server not reached | 网络 / DNS / 代理层问题，请求没到服务商 |

列表上方提示：“探测为匿名请求，404/403 等表示已到达服务器，属正常”。
